# CV Sergio

Currículum Vitae de **Sergio Jurado** (`senseikatana`), implementado con distintos frameworks para comparar rendimiento y DX.

## Versiones

| Versión | Tech stack | Estado |
|---|---|---|
| [`astro/`](astro/) | Astro | ✅ Activa |
| [`nuxt/`](nuxt/) | Nuxt 3 + Vue | ✅ Activa |

## Instalación

```bash
# Astro
cd astro && npm install && npm run dev

# Nuxt
cd nuxt && npm install && npm run dev
```
